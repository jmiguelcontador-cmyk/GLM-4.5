# Formato do glossário

`<tema>_glossario_v1.md` é a linguagem canônica do workspace. Lições, exercícios e registros seguem a terminologia dele. Montá-lo faz parte do aprendizado: resumir um conceito numa definição curta é evidência de que o usuário o entendeu.

## Estrutura

```md
# Glossário: {Tema}

{Uma ou duas frases sobre o tema coberto.}

## Termos

**Fato gerador**:
Situação definida em lei como necessária e suficiente para fazer nascer a obrigação tributária.
_Evitar_: momento do imposto, gatilho
_Fonte_: [CTN, art. 114](URL conferida)
```

## Regras

- **Só entra termo que o usuário já entende.** O glossário registra conhecimento comprimido; não é dicionário para estudar. Espere o usuário usar o termo corretamente.
- **Seja opinativo.** Quando houver várias palavras para o mesmo conceito, escolha a melhor e liste as outras em _Evitar_.
- **Definições curtas.** Uma ou duas frases sobre o que o termo É.
- **Cite a fonte** quando a definição vier de lei, norma ou documentação oficial.
- **Use os próprios termos do glossário** dentro das definições.
- **Agrupe em subtítulos** quando surgirem grupos naturais.
- **Explique ambiguidades.** Ex.: "Neste workspace, 'receita' significa receita bruta; a líquida é chamada de 'receita líquida'."
- **Revise conforme o entendimento evolui.** Atualize no próprio arquivo; não deixe definições velhas.
